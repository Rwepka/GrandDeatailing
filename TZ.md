# ТЗ: доработка сайта GRAND DETAILING

Документ фиксирует объём правок, критерии приёмки, технические решения и порядок проверки. Создан по запросу заказчика; дополняется по ходу выполнения.

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Проект | Сайт детейлинг-студии GRAND DETAILING |
| Домен | https://grand-detailing.ru |
| Хостинг | REG.RU, shared-хостинг (Apache + PHP + MySQL) |
| Стек | PHP 8.x, MySQL/MariaDB, PDO, vanilla JS, CSS без сборщика |
| Репозиторий | https://github.com/Rwepka/GrandDeatailing |
| Локальная среда | Windows, PHP 8.4.28, MariaDB 11.4.14, `http://localhost:8000` |
| Город / регион | Туапсе, Краснодарский край |

## 2. Цель

Привести публичную часть сайта к единой дизайн-системе, убрать металлические текстуры, стандартизировать типографику и отступы, сделать квиз записи удобнее, исправить расчёт стоимости заявки по классу кузова и усилить SEO-позиции по локальным и сервисным запросам.

## 4. Критерии приёмки

1. **D1–D4**: в публичной шапке на всех страницах нет кнопок «Выйти», «Записаться», «Тонировка»; в админ-навигации нет «Главной»; фон шапки равномерный, без градиентной маски.
2. **G1**: в CSS отсутствуют `feTurbulence` и металлические `linear-gradient`; цвет карточек — `#7e8891`.
3. **G2–G3**: H1/H2/H3 и цены на всех публичных страницах используют единые размеры; кнопки не примыкают вплотную к тексту/полям.
4. **G4–G5**: карточки услуг и классы автомобиля в калькуляторах имеют одинаковую высоту в пределах сетки.
5. **G6**: у карточек видимая светлая обводка.
6. **G7**: `font-family` body — Inter, шрифт отдаётся с домена (без внешних запросов).
7. **G8**: нативные radio не видны; выбранный вариант подсвечивается; клавиатурный фокус виден.
8. **G9**: шаги квиза: пройденный — зелёный, текущий — белый со светлым контуром, будущий — белый; клик по шагу работает; вперёд нельзя перейти без заполнения предыдущего шага.
9. **G10**: логотип «GD» цвета `#7e8891` используются на всех страницах, крупный.
10. **S1–S7**: title/description уникальны, H1 один, JSON-LD валиден, sitemap содержит все публичные URL, приватные страницы noindex.
11. **B1**: при создании заявки на «Универсал» в `booking_items.price` сохраняется цена для универсала; для «Седан» — цена седана.
12. **Регресс**: все публичные и админ-страницы отвечают 200, PHP-ошибок нет, мобильная вёрстка без горизонтального скролла.

## 6. Вне объёма

- Переезд на другой хостинг/стек, сборщик фронтенда.
- Изменение бизнес-логики статусов заявок, ролей, оплат.
- Массовая генерация новых услуг/городов.
- Гарантия позиций в поиске: SEO-мероприятия создают технические и контентные предпосылки, но результат зависит от внешних факторов и модерации поисковиков.

## 7. План проверки

1. PHP lint всех файлов.
2. HTTP-смоук публичных страниц и админки под ролью администратора.
3. Проверка title/description/H1 и JSON-LD.
4. Проверка sitemap/robots, canonical, noindex.
5. Мобильная и десктопная вёрстка: отсутствие горизонтального скролла, читаемость, состояния кнопок.
6. Сценарии квиза: блокировка перехода, зелёные/белые этапы, возврат назад.
7. Создание заявки мастером для «Седан» и «Универсал», сверка `booking_items.price`.
8. Проверка шрифта Inter, цвета карточек, обводок и отсутствия текстур.

## 8. Деплой и индексация

1. Выгрузить изменённые файлы на REG.RU (FTP/SFTP), не перезаписывая `config/config.php` и `storage/`.
2. Проверить `config('app.url') = https://grand-detailing.ru`, `debug = false`.
3. В админке заполнить коды подтверждения Google Search Console и Яндекс.Вебмастера (страница «Настройки»).
4. В Search Console добавить сайт, подтвердить, отправить `https://grand-detailing.ru/sitemap.xml`.
5. В Яндекс.Вебмастере добавить сайт, подтвердить, отправить sitemap, проверить «Индексирование».
6. Проверить `robots.txt`, `sitemap.xml`, canonical и 200 на ключевых страницах.
7. Для локального SEO синхронизировать NAP (телефон, часы) с Яндекс.Картами, 2ГИС, Zoon и другими справочниками.

## 9. Вопросы и риски

- **Телефон в справочниках**: Zoon и Яндекс-отзывы указывают `+7 (988) 413-07-77`, на боевом сайте — `+7 (988) 413-57-77`. Нужно подтвердить актуальный номер и привести все источники к одному значению.
- **Режим работы**: справочники указывают Пн–сб с перерывом, сайт — ежедневно 10:00–19:00. Требуется синхронизация.
- **Поисковая выдача**: гарантировать позиции по широким запросам («детейлинг», «полировка») нельзя; приоритет — локальная выдача Туапсе и карточки услуг.
- **Доступ к проду**: для загрузки изменений и проверки индексации нужны FTP/панель REG.RU и аккаунты Search Console/Вебмастера.

## 11. Ревизия 2 (24.11.2026)

Актуальные правила после замечаний заказчика:

1. **Шапка**: нет кнопок «Выйти», «Записаться», «Тонировка» ни на одной странице. Пункты меню: Главная, Услуги, Новости, Отзывы, Контакты.
2. **Логотип**: GD цвета `#7e8891` на всех страницах (не только на главной).
3. **Услуги**: вся информация (краткое и полное описание, «Что входит», «Как проходит», цены, длительность) — в БД `services`; заполняется через `/admin/services/create` и `/admin/services/{id}/edit`. Статические страницы услуг запрещены.
4. **FAQ**: отдельная вкладка `/admin/faqs`; таблица `faqs`; блок и `FAQPage` только на главной.
5. **Регион**: упоминания допустимы в title/description, JSON-LD, адресе и блоке под калькулятором на главной. В H1 и остальных видимых текстах — нет.
6. **Блок под калькулятором**: фраза «и других посёлков побережья» заменена на «и др.»; предложение «Студия находится... Запишитесь онлайн...» удалено.
7. **Анимации**: чекбоксы и сегментированные radio анимированы (заливка, галочка, точка, плавные переходы).
8. **Производительность локально**: `db.host = 127.0.0.1` на Windows — убирает IPv6-таймаут ~2 с.
9. **Архитектурный документ**: `docs/ARCHITECTURE.md` — обязателен к прочтению перед правками.
